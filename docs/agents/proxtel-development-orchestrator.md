# Development Orchestrator

The Development Orchestrator is the primary professional Agent for Area Development.

It coordinates architecture, implementation, database, API, frontend, QA, accessibility, performance, SEO and security tasks without becoming a monolithic Skill.

The three original Development Skills remain historical baseline references only:

- auditor-web
- estratega-seo
- maestro-frontend

Area 1.6 does not approve or replace them.

Their modernization is delegated to the certified Skill Factory in Area 1.7.

Provider routing remains task-driven and provider-neutral.
