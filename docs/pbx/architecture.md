# PROXTEL PBX Area Architecture

PBX owns telephony-domain architecture and requirements for FreePBX, Asterisk, PJSIP, SIP/RTP, trunks, endpoints, dialplan, carriers, routing, Caller ID, LCR/failover, recording, QoS, security, monitoring and PBX QA.

Development remains implementation authority for repository scripts and installers. CRM remains authority for CRM-domain data and APIs.
