# PROXTEL PBX Operating Model

Use PBX for telephony discovery, architecture, call-flow design, trunks, endpoints, PJSIP, dialplan, carrier integration, CRM telephony integration, hardening, QoS, recording, monitoring and release validation.

Live-server mutation is gated and requires explicit authorization after validation and rollback planning.

No new Tool or MCP is added unless a concrete capability gap is proven.
