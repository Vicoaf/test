# PROXTEL AI AGENCY Production Runtime

Production Runtime v1 converts the certified Agency into a reusable project operating system.

A project is bootstrapped with a .proxtel directory. Tasks are routed deterministically to the appropriate Agency areas and converted into execution packets.

Default provider plan:
- Claude: architecture and complex analysis.
- Codex: implementation worker.
- Antigravity: research and independent audit.

Execution is not autonomous by default. Approval gates remain mandatory for Git, dependencies, deployment, destructive database operations and production/PBX mutation.
