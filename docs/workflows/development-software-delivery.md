# Development Software Delivery

This workflow is the canonical Development delivery process for PROXTEL AI Agency.

It separates read-only discovery, planning, local implementation, deterministic validation, web-quality validation, independent review and release readiness.

READY never implies automatic deployment.

For important changes, implementation and review should be separated when practical.

User-facing web work should include browser/responsive, accessibility and performance validation when applicable.

The workflow does not require one specific AI provider.
