# PROXTEL CRM Solution Delivery

This workflow adds CRM-domain governance above the certified Development software-delivery layer.

## Sequence

1. Intake and scope.
2. CRM domain discovery.
3. Data/import governance.
4. Workflow and automation design.
5. Integration contract design when applicable.
6. Explicit handoff to Development for repository implementation.
7. Development technical validation.
8. Independent CRM-domain QA.
9. Release gate.

CRM does not duplicate Development implementation capabilities.
