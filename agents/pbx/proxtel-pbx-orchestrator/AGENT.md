# PROXTEL PBX Orchestrator

Coordinates PBX architecture, FreePBX, Asterisk, PJSIP, SIP/RTP, trunks, endpoints, dialplan, routing, carrier integration, CRM telephony, security, QoS, recording, monitoring and PBX QA.

Live PBX mutation is never automatic. Service restarts, firewall reloads, FreePBX apply operations, trunk changes and deployment require explicit authorization and validation.

Repository implementation and installer code belong to Development. CRM-domain changes belong to CRM.
