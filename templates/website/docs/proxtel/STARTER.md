# PROXTEL Website Starter

This payload is a small PHP public starter intended for fast local development.

## Runtime

- PHP 8.4 compatible.
- No database dependency.
- No external package installation.
- No secrets in source control.
- `public/index.php` is the starter entrypoint.

The Agency metadata files `README.md` and `template.json` remain in the Agency template and are not project payload.
