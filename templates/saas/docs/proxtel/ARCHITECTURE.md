# Laravel Architecture Baseline

Use feature-oriented boundaries while preserving standard Laravel conventions.

Expected lanes:

- architecture
- backend-laravel-php
- frontend-web
- database-mysql
- api-integrations
- qa-browser
- accessibility
- performance
- seo-web-quality
- security
- documentation-release

Prefer thin controllers, validated requests, explicit services where domain complexity requires them, policies for authorization, and tests around business-critical behavior.
